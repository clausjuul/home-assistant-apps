## Meal Planner
Madplan, opskrifter, brugerprofiler, indkøb og AI-chat.

**Status:** Repositoryet er klargjort. Meal Planner vises først i app-butikken, når den første version er udgivet og dens image er kontrolleret som offentligt tilgængeligt. En tom app-liste indtil da er forventet.

Se [installation og flytning af data](meal-planner/DOCS.md).

Udvikling foregår i et separat privat repository. Her offentliggøres kun godkendte installationsoplysninger og dokumentation. Appens kørbare Docker-image er offentligt. Personlige data og API-nøgler offentliggøres ikke.

## Opdateringer
Versionen i appens manifest opdateres automatisk efter en vellykket udgivelse. Home Assistant opdager derefter den nye version ved opdatering af app-butikken.
